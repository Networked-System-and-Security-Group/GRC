# GRC 论文采样独立闭环：Tofino2 短测

旧热力图测量的是旁路采样器，新目录 `expr-p4-paper-loop` 则由新版采样器提供全部 RTT 反馈。独立构建 `paper-loop-s16-q9` 的编译后 context 和 BFRT 文件没有旧 PSN 匹配表或 `W` 窗口表。旧实验、脚本和结果保留。

- 论文 §III-B / 算法 1：64 桶 × 16 槽；双向 QPN 映射供数据和 ACK 重建连接身份；CRC32 哈希 PSN 选槽，24 位 identifier 验证身份；保护未过期记录、重传刷新、ACK 命中即消耗，使用纳秒时间戳计算 RTT。把低于上次有效 epoch RTT 减一个实际 RNIC RTO 的样本排除在反馈之外。
- §III-C / 算法 2：控制面读取采样器的累计 RTT 和样本数，维护滚动基线、按实际 epoch 计算和更新速率。此次采用等权 `w=1`。线上 RTT 和用 64 ns 单位，静默采集另保留全精度累计和。
- §III-D / 算法 3：控制面将参考速率换成字节预算写回，保留正积压；交换机用 RED/CE 产生给真实 QP 的 CNP，网卡用原生 DCQCN 响应。CNP 生成、接收/处理和数据包数独立对账。

| Tofino2 + RNIC 条件 | 正常 ACK | 被新版接纳并由控制面消费的 RTT 样本 | 精确匹配率 | 平均 RTT | CNP 生成 / 网卡处理 |
|---|---:|---:|---:|---:|---:|
| 1 QP，40,000 次 Write | 42,511 | 42,492 | 99.9553% | 2.192 µs | 0 / 0 |
| 64 QP，定时 5 秒 | 947,939 | 946,742 | 99.8737% | 5.495 µs | 27,088 / 27,088 |

两条流量记录的离线重算及结束后二次快照通过。64 QP 时两个测试口各有 1 个 IPv6 RS，由网卡物理计数单列、未进入 RDMA 数据及 ACK 统计；1 QP 无背景帧。两次无新 NIC 错误、重传或被忽略的 CNP；没有模糊回绕的控制汇总。测得最大控制周期分别为 5.604 ms、5.823 ms（配置目标 1 ms）。单次短测不用于代表长时间表现、RTT 测量误差或论文 WAN 的吞吐与公平性。

同一 q9 构建在空闲 ASIC 上另用包发生器验证了冲突保留原时间戳、重传刷新、命中即清除、重复 ACK 拒绝、过期可替换、24 位 PSN 回绕和 RTT 下限。15 个定向包事件得到 4 个有效 RTT、2 个失配和 1 个匹配后 RTT 拒收；控制寄存器和纳秒累加器一致。测试床真实 RTT 低于一个 RNIC RTO，下限由定向测试显式设置来验证。定向包测毕已冷启动清除注入状态。未用软件模型，未启动大矩阵。

实验根目录和入门命令见 [README](../../../expr-p4-paper-loop/README.md)。原始试验 ID：`cf5af585cb604fb684b3d15e0232074a`、`2059c6ed9ade4f04b502dc5901f7f67c`。构建描述在 `builds/paper-loop-s16-q9/build.json`；逐次证据在 `results/raw/paper-loop-s16-q9/`；ASIC 诊断和部署凭据在 `results/qualification/`。构建来源 SHA-256：`2124db34dc264a576f2417ffb62f1f69ae4ca3ef94a0a4f9d7f6329a5bfa8822`。

早期 q8 的第一次短测因快照长时间持锁导致控制周期越界，退出后 QP 安装无法订阅；第二次被交换机编译互斥检查拒绝。记录均保留。q9 去掉快照内人为等待，保留调用方的静默间隔、独立 NIC 对账及结束守卫；部署也增加了编译中拒绝冷启动的检查。
