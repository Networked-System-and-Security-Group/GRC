# GRC 独立闭环：替换旧旁路采样热力图

用真正消费新版 RTT 的 Tofino2 闭环重新测量身份命中率。每次只部署一个独立闭环构建，无旧 PSN 表和 `W`。旧“论文式采样”热力图继续作为旁路对照的历史证据保留，不覆盖其原始结果。

- 一对测试主机地址、同一台 Tofino2、真实 RoCEv2 RNIC、未限速、64 KiB Write、MTU 1024，与旧热力图的流量条件对齐。
- 固定 256 个桶；每桶 16 / 32 / 64 槽；并发 QP 1 / 2 / 4 / 8 / 16 / 32 / 64；每 QP 固定 40,000 或 400,000 次 Write。42 格，每格三次独立冷启动，共 126 次。每次测量重装映射，控制面消费新版 RTT，网卡响应 CNP。历史同范围子矩阵的 126 次有效运行耗时约 2 小时 40 分钟，可用于粗估；新版和重试会改变耗时。
- 每个点按三次固定种子随机顺序排列。试验只按对账、环境和来源完整性判定，通过率高低不影响有效性；失败尝试保留，每点每次启动最多重试至三次。重启同一个 cohort 时跳过已经审计通过的点。

图的两个面板分别是 4 万 / 40 万 Write，横轴 QP，纵轴 S。颜色为 `100 × (采样身份命中数 / 正常 ACK 数)`，每格显示三次中位数和最小–最大值。身份命中但被 RTT 过滤的 ACK 仍算身份命中，另列实际纳入控制的 RTT 数；缺失格灰色。新图描述的是新版自己驱动反馈下的表现，不能把它与旧旁路图的差值全部归因于某一个机制。

[运行与状态命令](commands.sh)。编排机上在 tmux 执行 `bash heatmap-commands.sh run`。批次使用已经资格验证的编译物，启动前重新核对源码、远端文件哈希、固件/驱动/perftest 和实验口环境。不改变主机网络设置。

三档构建均在 Tofino2 和真实 RNIC 上通过短测，本地已从原始记录复算。三次均通过 Write、ACK、CNP 对账，控制面消费了全部通过过滤的 RTT。编排机预检通过。这三次短测独立于下面的正式统计。

## 正式结果（2026-11-15）

本批次在 Tofino2 和真实 RNIC 上完成，从第一条正式试次开始到最后一条结束约 155 分钟。128 次尝试中，126 次通过核验，每格 3 次。两次无效记录均保留：一次交换机生成 2,166 个 CNP、发送端网卡处理 2,165 个；另一次主机背景计数和两端物理帧计数对不上。两个条件补跑后均齐全。126 次有效试次共观察 536,153,561 个正常 ACK、505,581,364 次身份命中；命中的样本均通过 RTT 过滤并被控制面消费，NIC 处理的 CNP 共 11,228,332 个，与 ASIC 生成数对账。有效试次中的可识别背景帧独立核算，没有混入 ACK 分母。

4 万次下，32 槽七个 QP 档位的中位数均不低于 99.94%。40 万次下，32 槽到 64 QP 时只有 90.56%，64 槽提高了 9.31 个百分点，三次均在 99.85% 左右及以上。这组条件下，64 槽值得保留。此图测量 identifier 能找到对应采样记录的比例；旧图的 PSN 窗口接受率和旧反馈下的旁路采样是不同口径，不将两批之差当作 identifier 的单独收益，也不据此推断 RTT 精度。

复现：用 `P4_PLOT_PYTHON=<带 Matplotlib 的解释器> bash commands.sh analyze <本地 cohort 绝对路径>`。先用 `scripts/heatmap.py audit` 逐次复算，再调用 cohort 里的 `plot_final.py`。42 格标注已和复算 CSV 对照，PNG 300 dpi、SVG 为可编辑文字和矢量色块。原始记录、数据与图仅留在本地实验目录。
